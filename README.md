# 🎨 AtividadeCss

Projeto desenvolvido para praticar conceitos de HTML5 e CSS3, explorando estilização, estruturação de páginas web e responsividade.

## 🚀 Tecnologias Utilizadas

<p align="left">
  <img src="https://skillicons.dev/icons?i=html,css,git,github" />
</p>

- HTML5
- CSS3
- Git
- GitHub

## 📚 Sobre o Projeto

Este projeto foi criado com o objetivo de fortalecer conhecimentos em desenvolvimento Front-End, aplicando técnicas de estilização e organização de layouts utilizando CSS.

## 🎯 Funcionalidades

- Estruturação semântica com HTML5
- Estilização moderna com CSS3
- Organização de componentes visuais
- Layout responsivo
- Boas práticas de desenvolvimento

## 💻 Como Executar

Clone o repositório:

```bash
git clone https://github.com/Kauanmsx/AtividadeCss.git
```

Entre na pasta:

```bash
cd AtividadeCss
```

Abra o arquivo `index.html` no navegador.
